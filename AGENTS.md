This is an Expo/React Native mobile application (Expo SDK 57). Prioritize mobile-first patterns, performance, and cross-platform compatibility. Project rules are in `CLAUDE.md`; repeatable procedures are skills in `.claude/skills/`.

## Expo has changed — do not trust your training data

Expo ships breaking changes every SDK release. Before writing code that touches an Expo or React Native API, read the versioned docs: https://docs.expo.dev/versions/v57.0.0/ (index with LLM corrections: https://docs.expo.dev/llms.txt). Never answer from memory.

## Commands

```bash
npm run typecheck   # tsc --noEmit
npm test            # jest: domain, i18n, db (node:sqlite fake)
npx expo start      # dev server
```

`npx expo install` cannot reach the Expo API from the cloud sandbox. Add Expo packages with `npm install <pkg>@<version>`, taking the version from `node_modules/expo/bundledNativeModules.json`.

## Layout

- Routes live in `app/` (not `src/app/`). Every file there is a screen, `_layout.tsx` files define navigators. Import `Link`, `router`, `useLocalSearchParams` from `expo-router`.
- `src/domain/`: pure logic with tests in `__tests__/`. `src/db/`: SQLite schema, queries, backup. `src/ui/`: shared components (`kit.tsx`), theme, stores. `src/i18n/`: `pl.json` and `en.json`.

## Rules

- `ios/` and `android/` are generated by `expo prebuild` (CI does this). Never create or edit them by hand; configure native behavior in `app.json`.
- Expo Go only includes bundled native modules. A library with native code needs a development build.
- Prefer Expo modules over third-party libraries.
